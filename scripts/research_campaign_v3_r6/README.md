# Campaign v3 r6

Separately sealed continuation of r5-r2. The seven-model scientific design and
42,050-local-hour ceiling are unchanged. Successful native/REAP fixtures and
GPT/Nemotron coordination banks are imported; original task and shard identities
are retained. GPT's REAP limitation remains explicit.

`prepare --campaign ROOT --resume-from R5_ROOT` creates the source binding.
`validate-submit --campaign ROOT` requests four CPUs, 24 GiB and 180 minutes;
its reservation is 12 local hours and admission includes one equal recovery.
`validate-import` and `traverse` never submit scientific work. Full validation
exercises the installed tokenizer/input validator and the 243,747-row export in
isolated storage, then builds the canonical manuscript snapshot.

`submit --campaign ROOT` requires readiness. It prearms both failure owners and
the October 15 snapshot before retiring only verified pending predecessor owners.
The first real reader run recovers only audited pre-admission assignments; a
maximum-input coverage batch uses untouched original contexts when required.
Input preparation, admission and durable output are separately journaled.

Coordination, compact engineering and saved preparation have separate failure
capabilities. One extraction cache and one unpriced reader batch are permitted;
each model may have only one unpriced target role. Full production requires all
measured roles, 25% margin and separate WORK/FAST reserves. Exhaustion produces
explicit terminal dispositions without automatic source changes or a new campaign.

Local report/PDF completion and independently verified GitHub/Overleaf delivery
are distinct. Publication uses private Git indexes and an explicit source/figure
allowlist. Committed outputs and started stochastic assignments are never redrawn.
