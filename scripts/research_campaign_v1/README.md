# Research campaign v1

Public entry point: `run.py prepare|dry-run|submit|worker|status|closeout`.
Use the private WORK vLLM-cu129 Python. Scientific stages require a Slurm step;
`prepare`, `dry-run`, `submit`, and bounded `status` are orchestration commands.
`worker` accepts `--stage`, `--model`, `--threshold-index`, `--shard-index`, or an
immutable `--card`; array tasks map through the card's `array_cards` table.

The user-authorized launcher registers the entire finite graph, submits source
resolution and the October 15 snapshot, then accepts a held controller plus two
failure owners before releasing the deepest owner first. Every submission is
journaled before `sbatch`, verified by job ID and exact comment, and reconciled
after an ambiguous response. A started scientific unit is never redrawn. One
replacement is allowed only with zero-runtime, unset-Start, no-unit-start proof.
Controllers are bounded serial jobs with one CPU, 24 GiB for frozen task tables
and a 60-minute limit. The final failure owner has four CPUs and 180 minutes to
complete terminal exports. All serial expenditure and reservations are billed.

Read the campaign's `CAMPAIGN.json`, `PROTOCOL.json`, `GRAPH.json`, `LAUNCH.json`,
`REUSE.json`, stage receipts, and admission reports. Later configurations, masks,
task tables and measured role prices are immutable. Native sources are read in
place; original controllers and scientific implementations are preserved.
Do not edit bound source files after launch. Repairs require a fresh campaign
binding and exact reconciliation; ordinary progression needs no assistant process.

The pipeline joins card-v3 sources and the original 1,486-family fold universe,
derives absent saved-data summaries, measures absent native REAP/router quantities
on original saved sequences, freezes discovery-only configurations/masks, qualifies
physical loading and within-execution interventions, retains original-role prices,
and admits the complete residual production workload automatically. Normal QoS,
account `iscrc_miosr`, GPU partition `boost_usr_prod`, and bounded serial partition
`lrd_all_serial` are rechecked with exact Lustre project quota. Spending authority
is at most 42,050 local hours, reduced by expenditure/reservations, with 25% cost
margin, a 10 GiB scientific-output reserve, and explicit terminal infeasibility.

Signed multi-expert actions preserve native selection, correction bias, k, scales
and shared experts. Saved prefixes retain cumulative generation allowances and
completion penalty history. Pruning physically removes storage, including GPT's
unequal MXFP4 retained counts, under a fixed qualified KV capacity per model.
Memory curves use actual process residence from the common full-context
qualification fixture for each retained-count shape; ordinary generation
residence is exported separately so workspace history does not bias comparisons.
Original seven-class rendering/parsing is pinned in a private CPU dependency
closure; speculative acceleration is disabled and disclosed. Invalid or truncated
labels, conflicting original contexts, capped outputs and scientific failures are
retained without redraws. Strict accuracy is separate from semantic unknown bounds
and historical adjudication; the old candidate/J1 workflow is not restarted.

Final data, tables, figures, provenance and feasibility reports live under `output/`.
The October 15 report lives under `snapshots/2026-10-15/`. Root `REPORT_COMPLETE.json`
does not imply `SCIENCE_COMPLETE.json` is true. Support and 10,000-draw paired
whole-family simultaneous intervals condition on frozen selections. Degenerate and
unsupported intervals are unavailable; selection stability is reported separately.
One initial replicate has no run-to-run SD.

Bounded local verification:

```sh
PYTHONPATH=src:scripts/experimental_resume python -B -m unittest discover -s tests/research_campaign_v1 -v
```

GPU qualification runs inside the automatically protected graph. It tests native
selector fidelity, both action signs, multiple IDs, pulse boundaries, closure,
fixed full-context KV capacity, compact/full-resident masked equivalence and actual
storage release. It does not require sampled cross-run replay.
