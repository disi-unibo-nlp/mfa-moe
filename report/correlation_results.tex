\subsection{Completed vLLM replay and fixed-budget audit}
\label{sec:qwen-corr-audit}

The September 10, 2026 analysis of
\texttt{reasoning-vllm-untagged-v1} contains 4,647 attempts from 1,547 source
problems across six math benchmarks. It supersedes the September 8 numerical
snapshot in this report. GPQA-Diamond and MMLU-Pro are absent from this run
and from every total below; GPQA results from the earlier run are not pooled
into this snapshot. All 4,647 generation texts match their saved replay
continuations and analysis SHA-256 fingerprints. Every repeated group is
complete: 30 AIME 2024, 30 AIME 2025, and 40 AMC 2023 problems each have 32
distinct attempts, with no duplicate sample IDs or exact duplicate generations.
The other three datasets use one attempt per problem.

Generation uses vLLM serving \texttt{Qwen/Qwen3.5-35B-A3B-GPTQ-Int4}, at
temperature 0.6 and top-$p$ 0.95 with a 32,768-token completion budget. Saved
messages and continuations are replayed through
\texttt{unsloth/Qwen3.5-35B-A3B} with runtime 4-bit quantization. The generation
and replay checkpoints share the model family but use different quantization
formats and engines. Replay computes compact features at decoder indices
27, 34, 35, 36, 38, and 39, selected using the separate \texttt{probeTest} run.
Hidden features describe block inputs, not the exact post-attention router
inputs. Router confidence is $1-H(p)/\log 256$, where $p$ is the softmax router
distribution over all experts. The main analysis tests 83 scalar features;
entropy is omitted from separate testing because it is an affine transform
of confidence.
Aggregate-feature uncertainty uses 500 problem-bootstrap replicates and seed 42.
The additional views cover full reasoning and absolute token positions; no
sentence classifier or Schoenfeld class views were used in this untagged run.

\begin{equation}

The relation is preserved by token/layer averaging, so both quantities should
not be included together in an unregularized model or counted as independent
corroboration. The main metric-pair scan covers 13 aggregate features and 78

\subsection{Lexical events, storage, and implications}

The lexical detectors flag 2,513 backtracking, 1,741 contradiction, and 2,000
self-correction traces. Their pooled point-biserial associations with token
count are $0.566$, $0.425$, and $0.509$, respectively, with positive point
estimates in every dataset. Backtracking has negative confidence coefficients
in all six datasets, while self-correction is negative in five and slightly
positive on Minerva ($0.048$). These are surface-phrase detectors applied to
whole attempts, not independently validated reasoning episodes; the view
analyses reuse those whole-attempt flags rather than detecting local events.

Replay retains 61,964,775 continuation tokens. The projected selected-layer
raw payload is 1.904 TB (1.731 TiB), while persisted compact tensor artifacts
total 5.958 GB and per-dataset files total 8.047 GB. No raw router/hidden
tensors or expert weights are saved. Compact tensor bytes are approximately
0.313\% of the projected raw payload; the expanded reasoning-view summaries
are also retained in the dataset files.

For \emph{Guiding MoE Reasoning via Routing Intervention}, this run supplies
AIME confidence/margin candidates, exploratory pooled expert-ID associations,
and a position-dependent pattern requiring controlled follow-up. Priorities
are to prespecify how to handle remaining token-limit failures, validate
routing features beyond length and benchmark on held-out problems, and
compare position windows on common cohorts. GPQA-Diamond and MMLU-Pro require
separate runs before broader coverage claims. Neither full-trace correlations
nor expert-screen maxima establish that increasing confidence or forcing an
expert improves reasoning.
