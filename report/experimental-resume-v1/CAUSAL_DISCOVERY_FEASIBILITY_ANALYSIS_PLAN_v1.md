# Local routing-action discovery feasibility analysis, v1

This is a prospective analysis plan for the [21-family enrollment](CAUSAL_DISCOVERY_FEASIBILITY_MICRO_AMENDMENT_v2.json) and the [frozen action dictionary](CAUSAL_DISCOVERY_ACTION_DICTIONARY_v1.json). It is an exploratory 256-token branch-zero screen. The registered 48-family discovery maximum, 128-family mechanism validation, 96-family original-prompt utility scout and legacy 1,024-token endpoints remain separate. No analysis below converts this screen into those stages.

The unit of enrollment is a frozen discovery family. The candidate-to-substantive-verification transition has 12 families and the identified-approach-to-committed-planning-or-implementation transition has nine. Each has two fixed seeds. A family appears in only one transition. The 60 prespecified technical filler requests complete homogeneous eight-request batches and are excluded from semantic estimands; all 480 assigned requests remain in execution and failure receipts.

For each transition, the generator executes a zero-policy baseline and four active conditions: target experts at biases +0.5 and +1.0, and exposure-matched random experts at the same doses. Each active request has a same-prefix, same-seed zero-policy native sentinel in the same batch. Seed one reverses condition order. The original Qwen3.6 top-k=8 and shared expert remain intact. The corresponding action source is an observational native contrast; causal efficacy is determined only by these interventions.

The primary local semantic estimand within each transition is the family-average intention-to-treat risk difference in completing the fixed semantic transition within 256 newly generated tokens, comparing a target active request with its same-batch native sentinel. The triggering sentence is excluded. A candidate check must substantively evaluate an original computation or constraint; verification words alone do not count. An approach commitment must identify and pursue a concrete plan or implementation, not merely announce an intention. The endpoint includes nonfires, natural closures, length caps, generation errors and ungradeable outputs, all counted as no completed transition; we will report these categories separately. The prior two-Qwen full-prefix start decision is frozen before intervention and is never recalculated from a generated continuation.

Two independent arm-blind readers will rate target completion from the original problem, triggering context, complete emitted native prefix and generated reasoning continuation. The strict primary indicator is both readers accepting the target, with disagreement and at-least-one-reader results reported as measurement sensitivities. The blind frame contains the fixed target-transition label but no arm, expert, seed, family, gold answer, future native text or correctness field. A separate sealed map retains every assignment and its actual routing dose. Reader model outputs are LLM audits, not human ground truth or direct evidence of latent reasoning.

The four target-dose semantic contrasts (two transitions × two doses) form one simultaneous-interval family. Report family-clustered 95% simultaneous intervals, with seeds nested in family, and the full family-level paired differences. The +1 contrast is the leading discovery comparison and +0.5 measures dose response; this ordering was fixed before these new semantic outcomes. Matched-random active-versus-sentinel effects and target-versus-random differences are specificity checks in a separately corrected secondary family. Report exact denominators and uncertainty; do not add families, actions, seeds or reruns because an interval narrowly misses a threshold. Execution interleaving does not establish exact sign-flip randomization inference because engine numerics vary between identical native replays.

Routing first-stage analyses report, by assigned arm and transition, the expert-set occupancy at the first generated token, occupancy and dwell over observed reasoning tokens, actual action rows and target mass, membership changes, and the frozen random set used. Compare unordered top-k identities and native-sentinel first tokens against the zero condition and the prior native-only repeat distribution. The worker's per-token inactive expert-identity and weight checks are hard engineering receipts. A routing-speed or occupancy effect without a supported semantic effect is reported as routing control only.

The selected pool has material start-measurement disagreement: native Qwen3.6 and GPT-OSS votes are recorded before treatment and may be shown as descriptive strata, but do not change enrollment or the primary analysis. GPT-OSS accepted the frozen Qwen-negative controls, so its vote is not an adjudicated truth label. The 12- and nine-family cells can leave even large binary effects uncertain; this screen is for feasibility, direction and variance estimation. Accuracy and token cost from original prompts require the independent 16,384-token utility scout and are not inferred from these 256-token continuations. Any later validation or utility claim requires a separately frozen, family-disjoint study.
