# Routing first-stage addendum v1

Frozen before this addendum reads any generation outcomes. This secondary mechanistic analysis does not select policies or alter semantic contrasts, enrollment, seeds, horizons, or outcome rules.

For every frozen semantic contrast, use the left arm's named layer/expert targets and intended pulse slots to measure both its own continuation and the matched reference continuation. Pair exact prefix UID and seed. Never compare each arm's different target set as though they were the same outcome. Native-versus-native contrasts without a selected left target set are marked unsupported, not silently replaced.

The primary mechanistic endpoint is selected-expert inclusion per intended opportunity: sum of indicators that a selected expert appears among the eight executed expert IDs, divided by the fixed intended number of token × selected-layer-expert opportunities. Each intended pulse is 256 output positions, clipped only to the frozen horizon. A row predicting the reasoning-closure token is included, consistent with the qualified worker; later output positions are excluded. Natural stopping and reasoning closure contribute zero exposure to unexecuted intended positions. Their effects are part of this intention-to-treat endpoint, not a claim about routing propensity at identical hidden states.

Also report selected-expert inclusion per actually executed opportunity and the executed/intended exposure fraction. The former conditions on a post-intervention variable and is descriptive. Never assign a zero conditional rate when no opportunity executed. Report no-pulse exposure, closures, length stops, natural stops, generation errors and missing arrays by arm. Preserve every assigned prefix/seed cell. Generation errors have unidentified endpoint in [0,1]; successful runs with missing expert arrays have [0, executed/intended]. Exact assigned-population identification bounds accompany incomplete outcomes; no complete-case point estimate is presented as ITT.

Average both assigned seeds within prefix, prefixes within family, and then weight families equally. For each stage, the simultaneous secondary family includes every supported frozen semantic contrast for the one primary mechanistic endpoint. Use 50,000 paired family-bootstrap replicates and 95% Bonferroni percentile intervals, seed 20261004. For missing data, bootstrap the lower and upper family bounds and report an uncertainty envelope, explicitly distinct from a point-identified confidence interval. Keep unsupported contrasts in the inventory. No pooling across A/B/C/FRESH or horizons and no cross-stage selection claim. Small/degenerate family samples do not establish equivalence.

Saved per-action/per-layer telemetry gate L1 displacement and target counts are reported separately for each tensor-parallel rank and each action. These describe edited versus native routing at the same realized hidden states; they are not a paired native-completion gate-weight trajectory. Tensor-parallel rank measurements are not independent samples and are never summed together. Raw route archives contain expert identities only: full gate-weight total variation, velocity, acceleration and latent semantic control cannot be reconstructed.

Deliver exact source/manifest/array bindings, per-assignment exposure and inclusion tables, paired contrast estimates/bounds/intervals, per-arm operational and telemetry tables, and standalone figures. Use saved outputs only; no additional model inference, policy search, or outcome-dependent enrollment.
