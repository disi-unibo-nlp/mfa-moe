\section{Experimental Setup}

\paragraph{Current experimental scope.}
The active repository contains three complementary Qwen workflows.
\texttt{gepaLLMAsJudge} is an annotation-capability study that optimizes
Qwen3.6-27B and Qwen3.8-27B prompts for sentence-level Schoenfeld episode
classification.  It does not provide evidence about Qwen router dynamics.
\texttt{probeTest} is a
representation-probe replication that teacher-forces the 38 released
DeepSeek-R1 Schoenfeld traces through the official GPTQ 4-bit
\texttt{Qwen/Qwen3.5-35B-A3B-GPTQ-Int4} checkpoint and tests whether the next
sentence's label is linearly decodable at its causal pre-sentence boundary.
The separate \texttt{correlation\_pipeline} generates benchmark solutions with
Qwen3.5-35B-A3B, replays them through the matching checkpoint, and relates
router and hidden-state summaries to correctness and reasoning-event labels.

\paragraph{GEPA judge design.}
The GEPA workflow starts from 3,125 annotated units in 38 released DeepSeek-R1
SAT responses.  Complete responses are assigned to partitions before their
units are flattened, preventing neighboring units from crossing splits.  A
local \texttt{llama.cpp} server supplies Qwen predictions.  Each request
contains the SAT problem and the previous, current, and next response units.
The original context-aware seed instruction contains 21 audited synthetic
contrastive demonstrations.  The Qwen3.8 alignment instead imports the
40-example prompt selected by the earlier final fit as its external seed, so
it does not dynamically sample new demonstrations.  The implementation
supports inverse-frequency weighted exact match and an informative same-model
LLM-as-a-judge reward.  Prompt-selection rules are evaluated with nested
response-grouped cross-validation; the final-fit runs use a response-grouped
26/6/6 train/validation/test split.

\paragraph{Schoenfeld boundary-probe design.}
The probe workflow excludes the 38 synthetic \texttt{</think>} closing units,
which are all labelled Monitor, leaving the paper-matched 3,087 units.  Qwen
receives each SAT instruction as the user message and the released response as
a teacher-forced assistant continuation.  For a target unit, the feature is
the hidden state immediately before its first token, so the probe sees the
problem and preceding response but cannot read the target sentence.  Hidden-
state index 0 is the embedding output and indices 1--40 are the successive
language-model layers.

At each index, seven separate target-versus-rest logistic regressions use raw
2,048-dimensional activations, balanced class weights, L2 regularization with
$C=1$, and no standardization or PCA.  The paper-matched protocol uses a
target-stratified 80/20 sentence split with seed 42.  This is a replication
choice rather than a strong generalization design: all 38 response IDs occur
in both partitions.  The reported layer for each target maximizes accuracy on
that same test split.  For qualitative transfer inspection, the selected
probes are applied to 20 examples each from GSM8K, MATH, PRM800K, and
ProcessBench.  The seven binary scores are independently trained and
uncalibrated; their argmax is an inspection label, not a multiclass probability
or new gold annotation.  Only boundary vectors are stored; Qwen does not
regenerate the released or benchmark solutions.

\paragraph{Correlation-pipeline design.}
The pipeline separates \texttt{llama.cpp} generation from a teacher-forced
Hugging Face forward pass.  It stores router logits, selected expert
identifiers, and optional hidden states, then computes trace-level and
repeated-attempt correlations with correctness and lexical reasoning-event
labels.  The current run covers 6,627 scored traces from 1,745 source problems
across MATH-500, AIME 2024, AIME 2025, OlympiadBench, AMC 2023, Minerva Math,
and GPQA-Diamond.  AIME and AMC use 32 attempts per problem, GPQA uses ten
attempts with permuted answer choices, and the other datasets use one.  MMLU-Pro,
the eighth and last default benchmark, was not run.  Generation uses the
\texttt{UD-Q4\_K\_XL} GGUF with embedded native MTP speculative weights;
replay uses the matching BF16 checkpoint with runtime 4-bit quantization, so
the stages use different 4-bit formats.  All 6,627 traces are scored, and the
repeated AIME and AMC designs support problem-cluster and within-problem
analyses.

\paragraph{Table model and metric conventions.}
Every table caption identifies the evaluated model or models and the metrics
shown.  For classification, accuracy is the fraction of exact label matches,
balanced accuracy is the unweighted mean of class recalls, precision and
recall have their standard true-positive definitions, macro-F1 is the
unweighted mean of per-class F1, and AUROC measures score ranking across the
positive and negative classes.  Cohen's $\kappa$ is chance-corrected nominal
agreement, Kendall's $\tau_b$ is rank agreement under the fixed episode-label
ordering, and the GEPA composite averages their equal-weight $[0,1]$
rescalings.  Routing entropy is Shannon entropy of the softmax router
distribution; switch rate is the fraction of top-$k$ experts replaced from the
preceding token; top-$k$ overlap is adjacent-token Jaccard overlap; and router
margin is the top-1 minus top-2 router probability.  Unless a caption states
otherwise, $N$ and support are observation counts, $r$ is a Pearson-family
correlation coefficient, and confidence intervals are percentile bootstrap
intervals.

Qwen3.8 model-alignment run, and the Qwen3.5 boundary-probe artifacts formerly

analysis are complete for seven of eight default benchmarks; only MMLU-Pro
remains unrun.  Historical OLMoE and numbered-experiment outputs are archived
and are not pooled with the estimates in this report.
