\section{Immediate Work}

The agreed order of work is:
\begin{enumerate}
\item run one final GEPA alignment with the tutor-confirmed checkpoint and
medium reasoning budget, then freeze the selected prompt;
\item audit tensor semantics, shapes, dtypes, and serialized bytes per trace,
then retain only justified router and hidden-state locations;
\item prespecify the association measures, uncertainty, clustering, and
multiplicity treatment using cited methodology;
\item generate repeated attempts for AIME 2024/2025 and an affordable
MATH-500 pilot, then evaluate within-problem routing contrasts; and
\item expand to additional MoE families only after the pilot pipeline and disk
budget are stable.
\end{enumerate}
The detailed acceptance criteria and transcript ambiguities are maintained in
\texttt{NEXT\_STEPS.md} at the repository root.
