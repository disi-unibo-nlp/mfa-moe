\section{Immediate Work}

The agreed order of work is:
\begin{enumerate}
\item freeze and archive the seed prompt retained by the completed final GEPA
alignment, and reserve the locked test for a prespecified evaluation;
\item run the remaining MMLU-Pro generation, replay, and analysis stages;
\item fit a prespecified length-conditioned, dataset-aware correctness model
that respects problem clusters and keeps layerwise screening exploratory;
\item test whether the repeated-attempt router-confidence contrast survives
controls for length and token composition; and
\item expand to additional MoE families only after the pilot pipeline and disk
budget are stable.
\end{enumerate}
The detailed acceptance criteria and transcript ambiguities are maintained in
\texttt{NEXT\_STEPS.md} at the repository root.
