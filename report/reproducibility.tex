\section{Reproducibility Checklist}

\paragraph{Current artifact inventory.}
The judge includes grouped prompt-selection studies, final-fit validation,
and a frozen-prompt NVFP4 effort comparison. Boundary probes are complete
for Qwen, GPT-OSS, and Gemma; external probe inspection covers Qwen only.
Each correlation model has a complete six-benchmark corpus, with differing
class-label coverage. Guiding tables use complete Qwen identity $+1$,
identity $-1$, and margin-$1$ matched stochastic pairs. Incomplete conditions
are excluded from numerical comparisons. Independent annotation assessment,
response-grouped probe evaluation, and problem-cluster intervention
uncertainty remain outstanding.

\paragraph{Regenerating probe, effort, and guiding tables.}
Run \texttt{python3 report/generate\_current\_results.py} from the repository
root. It reads saved probe summaries and the judge-effort CSV, checks that
all reported guiding manifests are complete and share comparison contracts,
and verifies unique matching IDs, prompts, prompt tokens, per-attempt
sampling settings, and Boolean outcomes. It then recomputes pooled and
benchmark-specific correctness, flips, token counts, and truncation counts.
\path{report/current_results_sources.json} records input SHA-256 hashes
and the derived guiding statistics. The generator does not run inference,
rejudge answers, or calculate uncertainty intervals.

\subsection{Completed run and independent checks}

The numerical source root is
\path{results/correlation_pipeline/reasoning-vllm-v1}.
Under it, \path{analysis/unsloth--Qwen3.5-35B-A3B/correlations.json}
records completed analysis of 4,647 attempts. Source hashes are saved in
\path{report/correlation_tables_sources.json}; the audit separately records
the analysis SHA-256. Companion CSVs contain trace, problem, and expert
features. The \texttt{views-v1} directory contains full reasoning, seven
classes, ten position bins, overflow, and coverage summaries. Saved analysis
uses 500 bootstrap replicates, seed 42, minimum expert support of four
traces, and at most 128 ordered expert pairs.

The position-reference corpus has 4,647 traces and mean reasoning length
12,498.062 tokens. Its SHA-256 is\par\noindent
\path{99b71a50bf12f39ecec05f9034b3b07ff57236d2e53a7343f01caa791e108c1e}.
View population version 2 pools all reasoning tokens for full and position
views, and available tagged sentence tokens for class views. All attempts,
including limit hits, are retained with pairwise omission of missing features.

\paragraph{Independent audit.}
\path{report/audit_tagged_correlation_run.py} matches all generation records
to replay fingerprints, verifies available annotation fingerprints and sentence
offsets, checks selected layers and compact values, and validates inclusion,
correctness propagation, token-limit flags, and view coverage. It independently
recalculates saved binary and trace-level metric-pair coefficients across
20 scopes from CSV observations (52,199 coefficients). It additionally
checks 984 problem-mean Spearman and within-problem difference estimates
for whole continuation and full reasoning. It also checks reported expert maxima and
their continuous-metric associations. Counts and numerical discrepancies are
recorded in \path{report/correlation_run_audit.json}.

These checks do not independently rejudge mathematical answers or recompute
model activations, bootstrap intervals, or BH adjustments.

\paragraph{Regenerating the report.}
From the repository root, using Python with NumPy, SciPy, and Matplotlib:
\begin{verbatim}
python3 report/audit_tagged_correlation_run.py \
  > /tmp/correlation_run_audit.json
cp /tmp/correlation_run_audit.json report/correlation_run_audit.json
MPLCONFIGDIR=/tmp/moe-report-matplotlib \
  python3 report/generate_correlation_tables.py
cd report
latexmk -pdf -interaction=nonstopmode -halt-on-error main.tex
\end{verbatim}
The renderer writes coverage, correctness, class, lexical-event, expert,
and repeated-attempt tables, a compact plot atlas, and standalone PDF/PNG
figures. The atlas replaces the large numeric appendix in the compiled report.
The renderer reuses saved feature correlations and additionally computes
descriptive sampled-label counts, adjacent-sentence transitions, class-share
associations, and binned outcomes from fingerprinted inputs. These new
summaries and bin counts/ranges are saved in
\path{report/descriptive_plot_statistics.json}; router-value intervals use 500
source-problem bootstrap resamples with seed 42. No model is fitted. Original experiment outputs are unchanged.

\paragraph{Scope of reproducibility.}
Mutable local Docker tags and checkpoint names do not fix all underlying
binaries. Exact reproduction also requires resolved model revisions, image
digests, package versions, and the matching code revision. Saved contracts
and source fingerprints identify this report's numerical population.

\paragraph{Three-model report update.}
Run \texttt{python3 report/generate\_multimodel\_correlations.py} from the
repository root, then rebuild with the latexmk command above. This reads
the Qwen run above and the corresponding \texttt{reasoning-vllm-v1} runs
under \path{results/correlation_pipeline/gemma-nvfp4-nf4} and
\path{results/correlation_pipeline/gpt-oss-20b}. The generator verifies
coverage and recomputes reported aggregate coefficients from saved CSVs,
then writes comparison tables, figures, and both additional model atlases.
Source hashes and check results are recorded separately in
\path{report/multimodel_correlation_sources.json} and
\path{report/multimodel_correlation_audit.json}.
